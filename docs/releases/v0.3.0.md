# BYRBT Tools 0.3.0

首次公开发布。项目是 BYRBT 第三方工具，与站点官方无隶属关系。

## 安装

安装 Tampermonkey 后，打开本次 Release 的 `byrbt-tools.user.js` 附件并确认安装。无需下载整个源码 ZIP。Chrome / Edge 请按 Tampermonkey 提示启用用户脚本执行权限。

当前功能是按 UID 分层屏蔽用户，入口位于站点顶部“工具箱”。名单和规则先进入草稿，点击底部“保存设置”后生效；默认名单为空，配置仅保存在本机 Tampermonkey 中。

## 旧名称版本迁移

如果安装过 `BYRBT Tools · 用户屏蔽`，请先导出已保存配置，停用旧脚本，再安装本版、导入配置并保存。确认名单和规则一致后再移除旧脚本。不要同时启用两份；不同浏览器分别迁移。完整步骤见仓库的 `docs/MIGRATION.md`。

## 发布内容

- 正式名称为 BYRBT Tools，使用原创内嵌工具箱图标。
- MIT 开源；安装包保持可读，附完整许可文本。
- 提供稳定 Release 更新地址及 SHA-256 校验文件；开发分支提交不触发安装更新。
- 继承 0.2.2 已验收的原生表格布局、统一保存、同页返回与不撑高行的快捷按钮。

覆盖范围和未验收场景见仓库 `docs/COVERAGE.md`、`docs/VALIDATION.md`。公开链接安装、旧版名单迁移和完整在线更新链路的实测进度以验收记录为准。
